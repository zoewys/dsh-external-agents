# DSH 0.2.3 Compatibility Implementation Plan

> **For agentic workers:** Execute the steps below in this session, in order.

**Goal:** Install and run External Agents on the user's DSH 0.2.3-alpha.2, then upload the verified compatibility changes to GitHub.

**Architecture:** Compare the plugin's existing DSH integration with the installed desktop host and its published types. Keep the ACP driver intact unless a host API change requires a corresponding adjustment. Declare only the DSH versions covered by verification.

**Tech Stack:** TypeScript, Node.js, pnpm, DSH, ACP.

## Tasks

- [x] Install the unchanged lockfile with `pnpm install --frozen-lockfile --registry=https://registry.npmjs.org`; run `pnpm typecheck`, `pnpm test`, and `pnpm build` for a baseline.
- [x] Compare DSH 0.2.2-rc.5 and 0.2.3-alpha.2 declarations for the services imported in `src/host/dsh.ts`, prompt assembly in `src/host/subagent.ts`, and lifecycle events in `src/host/index.ts`. Upgrade the DSH dependency pins and regenerate `pnpm-lock.yaml` against the public registry.
- [x] Add regression coverage in `test/host.test.mjs` for any behavior affected by changed host APIs. Run the focused test before and after the source fix.
- [x] Adapt only the affected host integration; update `package.json` to version `0.3.3` and a verified `engines.dsh` value. Keep CLI approval handling and permissions unchanged.
- [x] Update the installation/version guidance in `README.md`. Run `pnpm typecheck`, `pnpm test`, `pnpm build`, and `pnpm pack`; inspect the resulting archive.
- [x] Install the archive through DSH, enable it, and verify an external Codex model is detected and answers a minimal connectivity prompt in a new test chat.
## Delivery

Review `git diff --check`, commit and push `codex/dsh-0.2.3-compat` to `zoewys/dsh-external-agents`, then verify its remote head. The `artifacts/` directory contains the prebuilt package and SHA256 checksum for direct download.

## Verification evidence

- Original baseline: 62 tests passed; typecheck and build passed.
- Compatibility version: 74 tests passed; typecheck, build, frozen lockfile with strict peer checks, and archive-content checks passed.
- Migrated setup routes to DSH's authenticated, owner-only Connection Fetch registry. Tests cover authentication, cross-origin rejection, nonce validation, body limits and disposal.
- Adapted incremental persona admission and image byte limits. ACP new/resume requests allow 60 seconds for cold CLI startup.
- Installed and enabled 0.3.3 on DSH 0.2.3-alpha.2. A native Codex chat returned `DSH Codex 兼容测试通过`.
- Local Codex uses the documented command override with the pinned ACP adapter, since the pre-existing global adapter was older. Personal configuration and credentials are excluded from this repository.
